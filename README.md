## 📖 项目简介

本仓库整理了云南大学 **大学物理实验 B（1）** 课程的部分实验报告及相关学习资料，包括实验报告 PDF、数据处理表格、GeoGebra 文件、实验配图和辅助视频等。

资料由 **启行录** 整理与制作，希望为实验预习、数据处理、报告复查和同学间交流提供方便。受资料留存情况限制，部分实验可能缺少原始照片或富文本元数据，内容也可能存在疏漏，欢迎共同补充和修正。

## 🚀 使用方式

### 在线查看

在上方目录中点击“查看资料”，进入对应文件夹后即可查看或下载文件。GitHub 无法直接预览的格式（如 `.ggb`、`.xlsx` 和 `.docx`）请下载后使用相应软件打开。

### 克隆到本地

仓库使用 [Git LFS](https://git-lfs.com/) 管理 PDF、视频等二进制文件。请先安装 Git LFS，再执行：

```bash
git lfs install
git clone https://github.com/Juese1216/YNU-college-physics-experiment.git
cd YNU-college-physics-experiment
git lfs pull
```

常用文件格式及推荐工具：

| 格式 | 内容 | 推荐工具 |
| --- | --- | --- |
| `.pdf` | 实验报告、实验指导书 | 浏览器或 PDF 阅读器 |
| `.xlsx` | 实验数据与计算表格 | Microsoft Excel、WPS |
| `.ggb` | 动态作图与拟合文件 | [GeoGebra](https://www.geogebra.org/) |
| `.docx` | 可编辑实验配图 | Microsoft Word、WPS |
| `.md` | 数据分析与思考题 | GitHub、任意 Markdown 编辑器 |
